GTA2 Brief TTS (English voices) — version {version}
===================================================

Installation
------------
1. Run GTA2BriefTTS-{version}-en-setup.exe.
2. Choose the folder that contains GTA2.exe (you can change it later in the app).
3. Start the “GTA2 Brief TTS” shortcut.

How to use
----------
1. Open GTA2 Brief TTS.
2. Check the game folder path (use “Browse…” next to the field).
3. Set in-game subtitle language, brief voice language, and volumes if needed.
4. Click “Save”, then “Start” — the app will launch GTA2 when needed and play mission brief voices.
5. Click “Stop” or close the window to end the session.

Contents
--------
  GTA2BriefTTS.exe   — graphical utility
  tts_cache/en/      — pre-recorded brief voices (no Internet required)
  config.json        — game folder, languages, volume (user settings only)
  pack_data.dat      — internal tables (do not edit)

You may set the GTA2_ROOT environment variable instead of the in-app folder.

Requires Windows 10 or newer.
